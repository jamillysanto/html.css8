# Mobile-First Responsive Website

A modern, clean, and fully responsive landing page designed with a **mobile-first approach**. This project was developed to provide a seamless user experience across all mobile devices using lightweight web technologies.

## 📱 Project Overview

This website serves as a digital business card or "link-in-bio" page. It is optimized for small screens, ensuring fast load times and intuitive navigation. The layout automatically adjusts to different screen resolutions, maintaining a professional look on both smartphones and tablets.

### Features
* **Mobile-First Design:** Developed specifically for mobile users first.
* **Clean UI/UX:** Minimalist aesthetic focusing on content and readability.
* **Fast Performance:** Built with vanilla HTML and CSS (no heavy frameworks).
* **Interactive Elements:** Hover effects and smooth transitions for better engagement.
* **Cross-Browser Support:** Tested on Chrome, Safari, Firefox, and Edge.

## 🛠️ Built With

* **HTML5:** Semantic structure for better accessibility and SEO.
* **CSS3:** Custom styling using Flexbox and Media Queries for responsiveness.
